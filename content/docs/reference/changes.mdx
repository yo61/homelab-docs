This is the exhaustive list: 160 changes to `flux-homelab` between the first commit on 2026-07-08
and 2026-08-28 — what changed, why it changed, and where to read the code.

Every feature, fix, refactor and revert is here, along with the handful of chores that changed the
cluster rather than a version pin.

For the story rather than the index, read [the build timeline](/explanation/timeline); for the
reasoning organised as themes, read [how this cluster evolved](/explanation/evolution).

<Callout title="Links go to a private repository">
`flux-homelab` is private, so the pull-request links below resolve only if you have access to it.
The commit messages they point at are where the detail lives — most carry several paragraphs of
reasoning that this table compresses to a sentence.
</Callout>

Renovate dependency bumps and documentation-only commits are omitted — they make up the rest of the
361 commits, and are better read in the repository's own history.
